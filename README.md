# The Vacuum's Alibi: One Line, 200 Characters

A robot vacuum explains, in its own deadpan voice, why it missed a spot.

`main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt`:

> The spot under the sofa was 96% cat hair, so per Section 4 of my firmware I classified it as the cat's property. Case closed.

125 characters, one line, deterministic — two runs produce byte-identical output.
